# Спецификация языка Alpaca

## Введение

Alpaca - это компактный, процедурно-структурированный язык общего назначения. Он подходит для создания консольных утилит и обучения программированию.

Программа на Alpaca состоит из одного файла с исходным кодом.

## Ключевые особенности

- Императивный стиль — вся логика строится на классических циклах (`for`, `while`) и условиях (`if`, `else`). Точкой входа в любую программу является функция `main`.
- Отсутствие классов. Для группировки данных используются структуры.
- Поддержка процедурного стиля программирования.
- Строгая типизация без неявных приведений типов.
- Обязательная инициализация переменных при объявлении.

## Система типов

Поддерживаются следующие типы данных:

| Тип | Описание |
|---|---|
| `int` | Целочисленный тип данных (32 бита) |
| `string` | Строковый тип данных |
| `bool` | Логический тип данных |
| `void` | Специальный тип для функций, не возвращающих значение |
| пользовательские структуры | Составные типы с полями |

## Лексика

### Идентификаторы

Идентификатор — это последовательность букв английского алфавита, цифр и символов подчёркивания `_`, которая начинается с буквы.

Ключевые слова — последовательности букв, зарезервированные для однозначности синтаксических правил, они не являются идентификаторами.

Регистр идентификаторов и ключевых слов имеет значение.

### Литералы

- Литералы целых чисел — это последовательность десятичных цифр. Не может начинаться с `0`, если содержит более одной цифры. Не допускаются литералы целых чисел, значение которых не попадает в диапазон 32-битных целых положительных чисел.
- Литералы строк состоят из нуля и более символов и окружаются двойными кавычками `""`.

### Пробельные символы и комментарии

Комментарии и пробельные символы могут появляться между токенами и игнорируются при разборе.

Комментарии начинаются с `/*` и заканчиваются `*/`. Вложенные комментарии не допускаются.

| Возврат каретки | 0x0D |
| Form feed | 0x0C |

### Escape-последовательности

## Синтаксис

Синтаксис описан ниже в нотации EBNF (диалект ISO/IEC 14977:1996). Допускаются только программы, которые сводятся к нетерминалу `program`.

```ebnf
program = "function" "main" "(" ")" block end_of_file ;

(* Инструкции (statements): *)

block = "{" { statement } "}" ;

statement = expression_statement ;

expression_statement = expression ";" ;

(* Выражения (expressions): *)

expression = additive_expression  ;

additive_expression = multiplicative_expression { ( "+" | "-" ) multiplicative_expression } ;

multiplicative_expression = power_expression { ( "*" | "/" | "%" ) power_expression } ;

power_expression = unary_expression [ "^" power_expression ] ;

unary_expression = primary_expression | "-" unary_expression ;

primary_expression = integer_literal
    | function_call_expression
    | "(" expression ")" ;

function_call_expression = identifier "(" [ expression_list ] ")" ;

expression_list = expression { "," expression } ;

end_of_file = ? признак конца файла ? ;

integer_literal = ? определён в лексике ? ;
```

|----------|-----------|-----------------|
| `:=` | 1(низший) | правая |
| `|` | 2 | левая |
| `&` | 3 | левая |
| `=`, `<>` | 4 | левая |
| `<`, `>`, `<=`, `>=` | 5 | левая |

| `*`, `/`, `%` | 7 | левая |

| унарный `-` | 9 | правая |
| `!` | 10 | правая |
| `.` | 11(высший) | левая |

## Семантические правила языка Alpaca

## Приведение типов

- Приведение типов не допускается.
- Для полей и переменных не допускается присваивание результатов выражений, тип которых отличается от указанного в объявлении.
- При вызове функции:
  - число аргументов должно соответствовать числу параметров, указанных в объявлении функции;
  - тип аргумента должен точно соответствовать типу параметра.

## Литералы

- Целочисленные литералы имеют тип `int`.
- Булевы литералы `true` и `false` имеют тип `bool`.
- Строковые литералы имеют тип `string`.
- Литерал `nil` представляет специальное значение для неинициализированных структур.

## Выражения

- Скобки `()` позволяют явно задать приоритет операций.
- Присваивание `:=` является правоассоциативной операцией: `a := b := c` эквивалентно `a := (b := c)`.
- Бинарные операторы являются левоассоциативными, например, `a - b + c` эквивалентно `(a - b) + c`.

### Арифметические операции для типа `int`

- бинарная операция «сложение»: `+`
- бинарная операция «вычитание»: `-`
- бинарная операция «умножение»: `*`
- бинарная операция «деление»: `/`
- бинарная операция «деление с остатком»: `%`
- бинарная операция «возведение в степень»: `^`
- унарная операция «минус»: `-`
- эти операции принимают и возвращают `int`
- деление на 0 приводит к ошибке выполнения программы

### Операции сравнения для типа `int`

- бинарная операция «равно»: `=`
- бинарная операция «не равно»: `<>`
- бинарная операция «меньше»: `<`
- бинарная операция «больше»: `>`
- бинарная операция «меньше или равно»: `<=`
- бинарная операция «больше или равно»: `>=`
- эти операции принимают `int` и возвращают `bool`

### Логические операции для типа `bool`

- бинарная операция «логическое И»: `&`
- бинарная операция «логическое ИЛИ»: `|`
- унарная операция «логическое НЕ»: `!`
- эти операции принимают и возвращают `bool`

### Операции сравнения для типа `bool`

- бинарная операция «равно»: `=`
- бинарная операция «не равно»: `<>`
- эти операции принимают и возвращают `bool`

### Операции сравнения для типа `string`

- бинарная операция «равно»: `=`
- бинарная операция «не равно»: `<>`
- эти операции принимают `string` и возвращают `bool`

### Операции сравнения для массивов `array`

- бинарная операция «равно»: `=` — проверяет, что две ссылки указывают на один и тот же объект
- бинарная операция «не равно»: `<>` — проверяет, что две ссылки указывают на разные объекты
- тип сравниваемых массивов должен быть одинаковым

## Массивы

- Выражение `array[expression]` создаёт одномерный массив, длина которого равна результату указанного выражения.
- Массивы являются ссылочными типами: присваивание меняет ссылку, не копируя массив.
- Массив существует как минимум до тех пор, пока существует хотя бы одна ссылка на него.
- Для ссылки на массив допускаются следующие операции:
  - доступ на чтение или запись к элементу по индексу с помощью выражения `array[index]`, где `index` имеет тип `int`.
- Доступ к элементу массива по индексу, выходящему за пределы диапазона, приводит к ошибке выполнения программы.

## Структуры

- Структура объявляется с помощью ключевого слова `struct`.
- Структура содержит поля, объявленные с помощью `field_declaration`.
- Для доступа к полю структуры используется оператор `.`, например: `object.field`.
- Поля структуры доступны для чтения и записи.
- При создании структуры её поля имеют значения по умолчанию:
  - `0` для типа `int`;
  - `false` для типа `bool`;
  - `nil` для строк и вложенных структур.

## Инструкции

- Тип выражения в инструкции `return` должен совпадать с типом функции — а если функция возвращает `void`, то `return` не содержит выражения.
- Инструкция `if` означает условное выполнение: если условие верно, то выполняется блок кода после условия, а иначе — блок `else`, если он есть.
- Инструкция `while` означает циклическое выполнение: пока условие верно, блок кода после условия продолжает выполняться.
- Инструкция `for` состоит из трёх частей: инициализация, условие, инкремент. Выполняется следующим образом:
  1. выполняется инициализация;
  2. проверяется условие; если оно ложно, цикл завершается;
  3. выполняется тело цикла;
  4. выполняется инкремент;
  5. переход к проверке условия.
- Инструкция `break` прерывает выполнение ближайшего enclosing цикла (`while` или `for`).
- Для вложенных инструкций `if` ветка `else` относится к ближайшему предшествующему `if`, для которого нет предшествующего `else`.
- В качестве инструкции допускается использовать только присваивания и вызовы функций. Использование иных выражений как инструкций вызывает ошибку компиляции.

## Переменные и области видимости

- Область видимости — это блок кода `{}`, в котором объявлена переменная.
- Переменная должна быть инициализирована при объявлении.
- Переменная доступна после объявления и до конца области видимости.
- Переменные, объявленные внутри одной области видимости, должны иметь уникальные имена.
- Переменные, объявленные в функции, доступны только внутри функции.
- Имена параметров функции должны быть уникальны в пределах функции.
- Имя переменной не может перекрывать имя параметра функции.

## Функции

- В программе должна быть ровно одна функция `main`.
- Функция `main` не принимает аргументов и не возвращает значение (имеет тип `void`).
- Вызывать функцию `main` не допускается.
- Если функция имеет возвращаемый тип, отличный от `void`, то она должна завершаться инструкцией `return`.
- Имена функций должны быть уникальны в пределах программы.
- Функции могут вызывать друг друга, в том числе рекурсивно.
- Функции могут быть объявлены в любом порядке, в том числе до их использования.

## Встроенные методы

| Метод | Описание |
|---|---|
| `void print(string s)` | Печатает строку `s` в стандартный поток вывода |
| `void println(string s)` | Печатает строку `s` и перенос строки в стандартный поток вывода |
| `void printInt(int x)` | Печатает число `x` в стандартный поток вывода |
| `int read()` | Читает один символ из стандартного потока ввода и возвращает его числовой код |
| `string readln()` | Читает строку до символа переноса строки из стандартного потока ввода |

## Завершение программы

- При завершении функции `main` происходит завершение программы. Процесс возвращает нулевой код.
- Ошибка выполнения программы приводит к аварийному завершению программы. Процесс возвращает ненулевой код.
