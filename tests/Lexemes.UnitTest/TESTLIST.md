# Список тестов

## Идентификаторы и ключевые слова

- [x] Разбор идентификаторов: `alice Bob C00L D_2 x`
- [x] Все ключевые слова по одному: `main array function return if else for while break nil var struct true false int string bool void`
- [x] Ключевые слова в составе идентификатора: `mainx iff variable voided int32 true_ nil2` → `Identifier`
- [x] Регистрозависимость: `Main IF True INT VOID` → `Identifier`
- [x] `function main() { }` — `function`, `main`, скобки
- [x] `while i < 10 { i := i + 1; break; }` — `while`, `break`, `:=`, `+`
- [x] `if a = nil then b` — `if`, `=`, `nil`, `then` → `Identifier`
- [x] Идентификатор, начинающийся с цифры: `1abc` → `IntLiteral(1)`, затем `Identifier(abc)`

## Литералы

### Целые числа

- [x] Литерал `0` (одна цифра) → `IntLiteral(0)`
- [x] Числа без ведущего нуля: `1234 56789` → `IntLiteral(1234)`, `IntLiteral(56789)`
- [x] Числа без ведущего нуля: `10 100 1000` → `IntLiteral(10)`, `IntLiteral(100)`, `IntLiteral(1000)`
- [x] Граница `int`: `2147483647` → `IntLiteral(int.MaxValue)`
- [x] Унарный минус: `-5` → `Minus`, `IntLiteral(5)`
- [x] Унарный минус с пробелом: `- 5` → `Minus`, `IntLiteral(5)`
- [x] Унарный минус перед границей `int`: `-2147483647` → `Minus`, `IntLiteral(int.MaxValue)`

### Строки

- [x] Разбор строк: `"" "0" "Hello, world!"`
- [x] Строка с пробелами внутри: `"  a  b  "`
- [x] Строка с пунктуацией внутри: `"a;b{c}(d)[e]"`
- [x] Разбор простых escape-последовательностей: `"\n\t\"\\"`
- [x] Escape-последовательности в контексте присваивания: `x := "line1\nline2"`

## Операторы, разделители и скобки

- [x] Все одиночные операторы и скобки: `+ - * / % ^ = < > . , ; ( ) [ ] { } & | !`
- [x] Все составные операторы: `<> <= >= :=`
- [x] `a < b | a > c | b = c` — операторы `<, >, =, |`
- [x] `a <= b & b >= c & a <> c` — операторы `<=, >=, <>, &`
- [x] Унарный минус в вычитании: `x - 5` → `Identifier(x)`, `Minus`, `IntLiteral(5)`
- [x] Двойной минус: `x - -5` → `Identifier(x)`, `Minus`, `Minus`, `IntLiteral(5)`
- [x] Унарный минус перед идентификатором: `-x` → `Minus`, `Identifier(x)`
- [x] Унарный минус перед скобкой: `-(5)` → `Minus`, `OpenParenthesis`, `IntLiteral(5)`, `CloseParenthesis`
- [x] `speed.x := v[0]` — операторы `.`, `:=`, скобки `[]`
- [x] `struct Point { int x; int y; }` — скобки `{}`, разделитель `;`
- [x] `(foo(x);0)` — разделитель `;`

## Пробелы и комментарии

- [x] Пропуск пробельных символов: `' '`, `'\t'`, `'\r'`, `'\n'`, `'\f'`
- [x] Комментарии между токенами: `/* comments */ a / /* should be */ b * c /* ignored */`
- [x] Пустой комментарий: `/**/ a`
- [x] Комментарий с ключевыми словами внутри: `/* if else while */ x`
- [x] Комментарий с `*` внутри: `a /* a * b ** c */ b`
- [x] Комментарий с `/*` внутри (вложенные не поддерживаются): `/* /* */ a`

## Ошибочные лексемы

### Целые числа

- [x] Литерал с ведущим нулём: `007` → `Error("007")`
- [x] Литерал с ведущим нулём: `00` → `Error("00")`
- [x] Литерал с ведущим нулём: `0123` → `Error("0123")`
- [x] Литерал с ведущим нулём: `0017` → `Error("0017")`
- [x] Переполнение `int`: `2147483648` → `Error("2147483648")`
- [x] Очень длинное число: `99999999999999999999` → `Error(...)`

### Строки

- [x] Незакрытая строка: `"abc` → `Error("abc")`
- [x] Незакрытая пустая строка: `"` → `Error("")`
- [x] Неизвестная escape-последовательность: `"\x"` → `Error("\\x")`

### Операторы и символы

- [x] `:` без `=`: `:` → `Error("expected '=' after ':'")`
- [x] Неизвестные символы: `@ # $` → три `Error(...)`
- [x] Кириллица: `привет` → шесть `Error(...)`

## Незакрытый комментарий

- [x] `/* abc` → `LexerException`
- [x] `a /*` → `LexerException`
- [x] `a /* c */ b /* d` → `LexerException`
- [x] `a /* comment` → `LexerException`
